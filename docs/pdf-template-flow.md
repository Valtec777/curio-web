# Fluxo de criação por modelo PDF - Plumareli

Os modelos PDF ficam dentro dos editores finais do Professor.

- Missão: `/professor/missoes/nova` -> `/modelos/professor/missao`
- Material/Caderno: `/professor/materiais/novo` -> `/modelos/professor/material`
- Avaliação: `/professor/avaliacoes/nova` -> `/modelos/professor/avaliacao`

Fluxo: baixar modelo -> preencher/gerar no ChatGPT -> importar PDF -> revisar campos -> escolher alunos -> salvar/publicar.

O PDF nunca escolhe alunos nem publica sozinho.
