# CURIÓ — Checklist de elementos e ícones próprios

Objetivo: substituir gradualmente símbolos Unicode, emojis e ícones genéricos por um kit visual próprio, mantendo consistência em site, plataforma, Canva e materiais impressos.

## Regras para os arquivos
- Preferência: SVG para ícones e elementos simples.
- PNG transparente para ilustrações/adesivos de mascotes.
- Criar cada ícone em versão normal e, quando necessário, versão para fundo escuro.
- Desenhar em grade consistente de 24x24 ou 32x32.
- Evitar detalhes finos demais.
- Usar cantos arredondados e traço compatível com a fonte Fredoka.

## 6. Elementos decorativos próprios
Gerar como kit de marca:
- estrela Curió lima;
- flor rosa Curió;
- pena/asa azul Curió;
- selo redondo com “C”;
- trilha pontilhada para Caminho;
- balões de fala Curió;
- cartões/stickers de “Pista”, “Tente outra vez”, “Muito bem” e “Próximo passo”;
- molduras de missão;
- selo “Caderno Curió”;
- selo “Modo Prova”;
- selo “Modo Pensar”;
- medalhas de conquista bronze/prata/ouro/raras;
- padrões discretos de estrelas, folhas e pontos para fundos.

## 7. Poses de mascotes que mais fazem falta
Para cada mascote, priorizar pelo menos:
- principal/saudando;
- pensando;
- comemorando;
- dando pista;
- lendo;
- escrevendo no caderno;
- apontando para conteúdo;
- erro/tente novamente sem expressão punitiva;
- conquista;
- avatar quadrado/rosto;
- sticker pequeno.

## Ordem recomendada de produção
1. Ícones de navegação do Aluno.
2. Feedback de acerto/erro/conclusão.
3. Acessibilidade/som.
4. Navegação Professor/Família.
5. Admin.
6. Stickers e elementos decorativos.
7. Poses adicionais dos mascotes.
